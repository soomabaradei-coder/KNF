# كنف بشرى الضيافة

وكيل ذكي يرافق ضيف الحملة من المطاف إلى المشاعر: يعرف مكانه ومخيمه وجدول حملته، ويستبق حاجته قبل أن يسأل.

الصفحة الحية: https://soomabaradei-coder.github.io/KNF/

- البناء: `python3 build.py` (يولد `index.html` من `src/`)
- الاختبار: `node tests/scen6.js`
- الدليل الكامل للتطوير: `CLAUDE.md`
- المرجع والقرارات: `docs/kanaf-reference.md`
